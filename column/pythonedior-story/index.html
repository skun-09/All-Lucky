Python Editor 開発秘話

制作物1作目となったPython Editorについて語ります。

Python Editorとは？

Python Editorとは、ブラウザ上でコードを書くことができるPython用の簡易的なコードエディタです。 簡易的といえど、保存機能もあるため多分ちょっと便利です。なにせよダウンロードがいらないというのは 個人的にかなりうれしいです。ぜひコードエディタを持っていない方は一回試してみてください。 サンプルコードも最初から書かれてありますので安心してください。

開発のきっかけ

開発のきっかけは実に単純です。便利さを追求したいからです。皆さんダウンロードってめんどくさくないですか？ 自分はめんどいです。特にちょっと使えればいいものにわざわざダウンロードは一番いやなタイプです。 ですがブラウザはダウンロードがいらずインターネット環境があればできるのです。 その利便性を生かしてこのエディタが開発されました。

きっかけ2

もう一つのきっかけは制作物をまだ作ってなかったからです。 このサイトはGoogle Adsenseのサービスを利用しています。Google AdsenseはGoogle社が提供する広告サービスです。現在審査に出しているため広告が表示されませんが、 その審査が通るためにやっているというのも理由の一つです。

実は、、、

実は、これ製作所ではPythonのジャンルに分類されていますが、本当はHTMLとCSSで作成されています。そのためPythonは使ってません。 ですがHTML/CSSはまじで知識が全くありません。 なのでAIに手を借りてもらいました。便利な世の中ですね。そして、このPYthonの仕組みって「Monaco Editor」というのを使いました。 「Monaco Editor」といはMicrosoft社が開発したVisual Studio Codeにも使われているコンポーネントを使っています。 そのため行数の表示、色分けなどいろんなことをしてくれました。最高！

おわりに

最後まで記事を読んでくれてありがとうございました。 Python Editorは製作所のPythonジャンルにありますので、ぜひ試してみてください。
