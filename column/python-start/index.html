Pythonを始めよう！

今回はPythonを始めるための入門を自分の体験談とともに解説します。

そもそもPythonとは

「自分の中」でのPythonを簡単に言うと、初心者向けのプログラミング言語です。 実際は機械学習など様々な分野で使用されとても汎用性のある言語ですが、 やはり簡単さが最初に浮かびます。一番最初にプログラミングをするときに Pythonを選んだ理由もこれです。また拡張機能のような「パッケージ」も大量にあるため 汎用性も高いです。

Python 
print("Hello World!")

これは「Hello World!」を表示させるプログラムです。一行で終わるとか最高ですね。

ですがいいところもあれば気になるところもあります。それは、、、処理速度の遅さです。 処理速度が遅いのはなかなかに致命的。とくに大量に計算するところでは大富豪の革命のように 最弱になります。まあ、最初のうちはそこまで気になりませんが。

始める準備

いきなりプログラミング！といっても環境を作らないとできるものもできません。 そのためにまずはPythonを書くことができるツールを用意しましょう。 ですがダウンロードとインストールはなかなか面倒くさい。 なので今回は普通にダウンロードをするソフトとブラウザでできるお勧めツール２つを紹介します。

1.VSCode（Visual Studio Code）

まあ定番ですね。自分も最初はこれで書きました。 何と言っても軽くて自由なところがいいです。拡張機能のおかげで自由にカスタマイズできるのがいいですね。 Pythonやるならこれで十分です。

2.Python Editor

ん？なにこれ？と思った方。実はこれS-labsオリジナルツールなんです。 気軽にプログラミングをやってみたい方にはうってつけです。 コードエディタ、実行結果のシンプルさなので自由さには欠けますが、まずはどんなものかを体験してみたい方にはお勧めです。 保存もできますよ。

🐍 Python Editorを使ってみる

コードを書く

まずは「Hello World!」を表示してみましょう！

Python 
print("Hello World!")

なんと簡単なのでしょう。これで完了です。実行してみましょう。 仕組みはprintというものにあります。 printはターミナルなどに指定の文字を表示してくれます。その指定の文字が ("Hello World!")です。絶対に""をつけてくださいね。絶対ですよ？ 理由はプログラミングの性質にあります。難しい話になりますが ""がないと文字列として見てくれません。なのでHello World!を打ったらエラーになります。 変数などを表示させたい場合は""を打たないようにしてください。今度は変数として見られなくなり変数の名前だけが表示されてしまいます。 なかなかに自分も忘れることが最初はありました。

さあ、ここまでくるとPythonの旅が始まります。頑張ってください！
