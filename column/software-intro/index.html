自分の使っているソフトはなに？

今回は現在使用しているソフト、ツールなどを紹介します。

一覧

現在使っているソフトの一覧です。マイナーなソフトもあるかもしれません。
・Visual Studio
・VSCode
・Unity
・Github Desktop
・Github
・Cloudflare
・Tiled
ざっとこんな感じです。多分もっとあるかも、、、？

1.Visual Studio

おそらく一番使っているソフトです。コードを書く人は大体入れてるソフトです。 自分は特にC++を書くときやUnityのコーディングで使用します。 このソフトの良いところはなんといっても書きやすさ。 文字を入力するとスマホの予測変換のように自動で単語を教えてくれます。また選択すると単語を自動で打ってくれるため、 効率が上がったような気もします。

ですがこんな便利なソフトにもちゃんとデメリットはあります。 それは「重さ」です。（物理的な重さではないですよ？） 比較になりますがVSCodeのようにサクサク動きはしません。 なので軽いコーディングでは不向きかもしれません。 大きめなプロジェクトで真価を発揮してくれます。

2.VSCode(Visual Studio Code)

第二のコーディングソフトです。大体このソフトも入れると思います。 自分は主にPythonで使用します。先ほど言ったように軽いので サクサク動きます。また、拡張機能のおかげで自由度が超高いです。 最近はあまり使ってませんが、このブログを書くためにもう一度使ってます。

拡張機能で便利な反面、環境構築が難しいのも特徴です。 自分はC++をVSCodeでやろうと思って地獄を見た人です。 Pythonなどでは楽なのでお勧めしますが、C++などでは大変なためあまりお勧めはしません。 「それでもやりたい！」という方は覚悟して臨みましょう。

3.Unity

ゲーム制作界隈で知らない方はいないと思うほど有名なゲームエンジンです。 自分もよく使ってます。自由度の高さのおかげで「とりまUnityで作るか」ができる最強ソフトと勝手に思ってます。 ゲームを作りたい方にはとてもいいのではないしょうか。

と初心者向けに言っているように見えますが実はとんでもないトラップがあります。 それは、、、、、最初の一歩が難しいことです。どういうこと？と思った方は 料理を思い浮かべてください。「簡単な料理」といったのに包丁で具材を切る工程があったり（これはそこまで難しくないかも） 挙句の果てには適量という不正確の極みがあったりするような感じです。（例えが下手なのは許してください） 結局何が言いたいかというと「思ってたのと違う」ということです。 ワクワクしながら開いたら英語のよくわかんない文字や形がたくさんあり最初は「？？？」となるのです。 ですがUnityは解説動画も多いため安心してください。

4.Github Desktop / Github

いわゆるセーブデータの保管庫です。 ここにファイルやデータを入れておくことでいつでも引き出せたり巻き戻したりできるツールです。 これに関してはデメリットが思い浮ばないほど最強です。 Githubアカウントは他サイトと連携できるものが多いため便利です。

5.Cloudflare

このサイトの管理をこのサイトで行っています。使いやすく日本語もあるため（ちょっと怪しいけど）もしサイト運営をしたい方にはお勧めなのではないでしょうか。 ストレージも無料で一部使えるためお勧めです。デメリットは、、、思いつく限りはないかな？強いて言うなら最初の操作は難しいと思います。ですがすぐ慣れると思います。

6.Tiled

「運が全て。」のマップ作成で使用しました。直感的な操作で分かりやすく、出来具合もとてもいい優れものです。 かなりマイナーなソフトで使う場面もかなり限られていますが「マップ作成をしたい！」という方には合うのではないでしょうか。

おわりに
