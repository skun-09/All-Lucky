C++を始めてみた

C++について始めてみた理由や、実際にゲーム制作をしてみて感じたことについて書いていきます。

C++を始めた理由

実はそこまで大した理由はありません。Pythonから初めて次はなんの言語をしてみようとなったとき、とにかくゲームが好きだった自分は「ゲームが作れる言語をしたい」という理由で、UnrealEngineなどで使用されているC++を選びました。 また、ゲーム以外にも「何でもできる」というのも選んだ理由にもあると思います。自分は利便性を追い求める人なのでC++が自分の性格と合っていたのかもしれません。

実際に書いてみる

まずはどのプログラミング言語でも絶対に書く気がするHello Worldを作ってみました。 もちろん最初は分からないことが多かったです。（特にPythonからやってる身としては、、、） 

#include <iostream>

int main() {

    std::cout << "Hello World!" << std::endl;

    return 0;
}

このプログラムは、コンソールに「Hello World!」と表示するだけの簡単なプログラムです。 作った感想としては、とにかく複雑に感じました。 ただ「Hello World」と表示させるだけでもかなり大変でした。 （大変というよりかはややこしい？） 比較になりますがPythonと比べると差は歴然です。 Pythonでは print("Hello World!") の1行で終わるのに対し、 C++ではこれだけのコードを書く必要があります。 最初はかなり大変でしたが{}で囲うというのはプログラムが見やすく感じました。

実際にゲームを作ってみて

最初はコンソールゲームから作ってみました。作ったゲームは数当てゲームと〇×ゲームです。 数当てゲームでは主にif構文の基礎を学べたと思います。その中でもやっぱり{}で囲うわかりやすさはとても良かったと思います。 Pythonでは改行とインデントで判断するのですが、C++ではインデントに加え{}で見れるので見やすかったです。 〇×ゲームでは関数を作ってみました。Pythonでは一回やってみたもののあまりわからなかったのですがUnityをやってたおかげなのか ちょっと理解できるような気がしました。難しかったですが学びになったと思いました。

SDL3に触る

SDL3を触ってみた感想では、Pygameのように感じました。 知らない人向けに説明すると、PygameとはPythonでゲームを作るときに使うライブラリのことです。 ウィンドウを作ってくれたりとなかなかに便利です。

話は戻りますが、SDL3はPygameのように「なんか同じようなことやってる？」と感じましたが、 さすがC++ということで複雑でした。特に根本のシステムを自分で宣言するのがPythonとは違うように思います。 ですが逆をいえば自分でシステムも決めることができるということですね。

おわりに

ここまで読んでくださりありがとうございます。これからもC++頑張ります！
