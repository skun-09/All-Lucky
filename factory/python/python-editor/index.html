💡 使い方

このエディタでは、ブラウザ上でPythonコードを書いて実行できます。

最初から入っているコードにもコメントで簡単な説明があります。 コードを書き換えて、いろいろ試してみてください！

▶ 実行 ボタンを押すか、 Ctrl + Enter でコードを実行できます。
